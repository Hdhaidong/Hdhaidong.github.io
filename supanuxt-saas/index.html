What's in the box

The unglamorous 60% of every SaaS, already done.

Auth & OAuth

Login flows wired end-to-end — social providers, session handling, protected routes. Users can sign in on day one.

Billing

Stripe subscription plumbing: plans, upgrades, downgrades, webhooks. The part everyone underestimates.

Data layer

Prisma schema plus tRPC endpoints — typed end-to-end from database to UI, with Pinia state management on the frontend.

AI-ready

OpenAI integration stubs built in, so the interesting part of your product starts immediately instead of after two weeks of setup.

Architecture

One typed path from UI to database — tRPC types flow end-to-end, so the client can't call what the server doesn't have.
