Flagship · Open-source agent hardware

Open Source · MIT Firmware

OpenWorker Deck

Give your AI coworker a body. A TRAE-style desk agent console + industrial gateway: Modbus (RTU/TCP), CAN/J1939, OBD-II, BLE 5.2, LoRa — smart link (MHS-native), on-device local model, detection, removable encrypted privacy cartridge. Compute-storage separation: pull the card, and the whole history leaves with it.

  • Four pillars: smart link · local model · detection · privacy storage
  • Physical Approve/Deny buttons for every device-write
  • Companion agent to OpenWorker, MHS-compatible
