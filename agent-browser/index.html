Agent Browser

A browser built around agents instead of tabs — the everyday surface where an agent's hands meet the open web.

Type: Desktop application Model: Agent-first browsing Status: Private product line
← Back to portfolio

What changes

Tabs are a filing system for humans. This is a workbench for agents.

Agentic web workflows

Browsing as a plan, not a pile: an agent opens what it needs, in the order it needs it, toward a goal you stated once.

Automated research passes

Recurring web research — pricing checks, release notes, competitor pages — runs itself on a schedule and reports only what changed.

Session capture

What the agent saw and did is recorded per session, so findings are traceable back to their pages — no unsourced claims.

Human supervision

Actions that write to the world — logins, purchases, submissions — pause for human confirmation, in keeping with the physical-consent philosophy across my hardware line.

Why it matters

The browser is where agents meet the real world. Right now they borrow ours.

Today's agents operate through tools bolted onto a human browser — fighting captchas, layouts and sessions designed for eyes. Agent Browser starts from the other end: the web as an API surface for supervised agents, with the human keeping the wheel. It pairs with Reddit Radar Workbench and Amazon Product Scout, which automate the research ends of the same workflow.
